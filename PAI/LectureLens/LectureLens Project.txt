LECTURELENS – MASTER PROJECT SPECIFICATION
Version: 2.0
Status: Production Portfolio Project

====================================================
PROJECT OVERVIEW
================

Project Name:
LectureLens

Objective:
Build a production-quality AI-powered study assistant that can ingest academic documents, create a searchable knowledge base, answer questions using Retrieval-Augmented Generation (RAG), provide verifiable citations, generate study material, and assist students with exam preparation.

The final application must demonstrate practical AI engineering skills including:

* Document Processing
* Data Extraction
* Text Chunking
* Embeddings
* Vector Databases
* Retrieval-Augmented Generation (RAG)
* Prompt Engineering
* LLM Integration
* Full-Stack Development
* AI Product Design

====================================================
ENGINEERING RULES
=================

The AI assistant working on this project MUST follow these rules:

1. Never generate the entire project at once.

2. Work strictly phase-by-phase.

3. Never skip phases.

4. Never generate files from future phases.

5. Before coding:

   * Analyze current project status.
   * Review completed phases.
   * Identify dependencies.
   * Identify risks.

6. After every phase:

   * Generate testing instructions.
   * Generate validation checklist.
   * Generate completion report.

7. Never proceed to the next phase until explicitly approved.

8. If requirements are ambiguous:

   * Stop.
   * Ask questions.
   * Wait for clarification.

9. Maintain clean architecture.

10. Prioritize:

    * Maintainability
    * Scalability
    * Reliability
    * Readability
